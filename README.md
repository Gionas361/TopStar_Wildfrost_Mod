# Top Star Wildfrost Mod

A comprehensive Wildfrost mod that introduces an entirely new tribe featuring 10 original characters with custom abilities, abilities, and mechanics.

## Overview

**Top Star** adds a new playable tribe called the **Caretaker Tribe** to Wildfrost, complete with a roster of unique characters, custom status effects, and special mechanics. This mod is designed to provide a fresh gameplay experience with new strategic options and visual identity.

## Features

### New Characters

The mod introduces 10 original characters to the game:

- **Starlight**
- **Solarflare**
- **Eclipse**
- **Stella**
- **Sui** - [Still in progress]
- **Zerk**
- **Khris**
- **Cat** - [Still in progress]
- **Jijikan**
- **Kaido**

Each character comes with custom artwork and unique card abilities.

### New Tribe: Caretakers

A fully realized tribe system with:
- Custom tribe UI integration
- Dedicated tribe selection in game menus
- Custom tribe display and flag
- Special narrative integration with existing game sequences

### Custom Mechanics

- **Advanced Status Effects** - New status effects including multi-status interactions and ability multipliers - [Still in progress]
- **Custom Ability Scripts** - Specialized scriptable abilities for unique gameplay moments

## Technical Details

### Built With

- C# / Unity
- Wildfrost Modding API (WildfrostMod framework)
- Harmony patching for seamless integration
- Custom asset builders for card creation

### Project Structure


This mod extends the base Wildfrost game and is designed to work alongside other mods. However, compatibility depends on specific mod interactions and conflicting card and effect id's.
